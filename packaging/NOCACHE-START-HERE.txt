GTA6 TEST 01 - COMPATIBILITY LAUNCHER WITH SHADER VALIDATION

1. Extract this small update into the existing Test 01 folder containing
   START-GTA6.cmd, game-path.txt, and the patched folder.
2. Run START-GTA6-COMPAT-VALIDATE.cmd. It reuses your saved game path. You
   can also drag the game folder or exact eboot.bin onto this launcher.
3. Let it load. After a crash or after closing the game, the combined report
   opens in Notepad. Send that report and describe the last visible screen.

This launch uses the same flags as START-GTA6.cmd plus --shader-validation.
It compiles shaders as needed, checks them before they reach the driver, and
reports the shader hash and validation error if a shader fails the check.
It uses a new diagnostic-runs subfolder with fresh saves and an empty Vulkan
pipeline cache. Only the small bundled runtime assets are copied there.

The report includes the loaded Windows DLL names and address ranges, so a
reported host fault can be matched to a module when that range was captured.
An address match identifies where a fault occurred, not its underlying cause.

The update uses the Test 01 executable already in your folder. A separate
gameplay run is required to assess compatibility.
